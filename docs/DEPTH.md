# 深度登记 跨境包裹扫描补传与妥投时效核验

规模：中型。使用者：跨境集运客服质控员。核心规则：以事件发生时刻重建路径，补传不改变既有妥投时间；承诺时钟按目的地节假日停表。

## 对账规则

输入原始逻辑行=最终采纳来源行+隔离来源行+重复行+空白行+分段表头。派生记录用_sources保存完整来源，因此分组不丢行。业务预期合计与上游申报合计之差等于逐行差异之和。结果按输入摘要、规则版本及参数产生唯一批次，事务写入；同源重跑只复用已有批次。

## 已知不覆盖

4MB以上文件需预先按业务键分批；不模拟生产支付与外部回调。人工复核只变更批次状态，不改写原始记录。

## 换版空档结算口径

资格空档内，运营要新账号扫描先进入时效计时，质控又不允许未核验来源直接形成赔付。本项目把「计时」与「结算」拆开：空档扫描照常推进路径与工作日小时，`provisional_expected` 反映暂算；只有资格落在某版本的 [start,end) 内（或经 `verified_scans` 核验）才写 `expected`。结算裁定只有「正式可结算」与「待核验挂账」两种，一包裹一条，页面、API、导出共享。换版是单事务的快照+指针切换，失败即回滚，旧版结算继续有效；同批次重复换版与同源重跑都不新增记录、不改金额。
